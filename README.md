## Адаптивная вёрстка

На телефоне блоки идут в одну колонку, меню открывается кнопкой, а категории расположены над карточками. От 40 rem навигация видна целиком, у карточек и формы появляются две колонки. От 60 rem каталог получает боковую панель фильтра и три колонки карточек. Сетка использует CSS Grid, шапка, карточки и кнопки — Flexbox. Переключение категории работает средствами CSS через `:has()` и состояние радиокнопок.

В таблицах характеристик на узком экране название и значение образуют отдельный вертикальный блок. На широком экране они стоят в одной строке. Для фотографий подготовлены WebP шириной 320 и 600 пикселей. Браузер выбирает файл по `srcset`, `sizes` и плотности экрана. Внутри `picture` есть исходный PNG.

## Доступность и проверка

Первое нажатие Tab выводит ссылку «К содержимому». На каждой странице один h1, у полей есть подписи, у фотографий — текстовые описания. Текущая страница отмечена через `aria-current`. Кнопка меню сообщает состояние через `aria-expanded`. Escape закрывает меню и возвращает фокус на кнопку. Нативный диалог быстрого заказа удерживает фокус и после закрытия возвращает его на вызвавшую кнопку.

В Chrome проверены все пять страниц при ширине 360, 430, 768, 1024 и 1440 px. Горизонтального переполнения страницы на этих ширинах не обнаружено. Проверены открытие и закрытие диалога с возвратом фокуса, мобильное меню и отбор категории «Хозяйство».

## Запуск

В каталоге проекта выполните `python3 -m http.server 8000` и откройте [главную страницу](http://localhost:8000/). Для проверки быстрого заказа выберите товар на главной, заполните форму и нажмите «Подготовить заявку». Подтверждение появится на странице. Формы демонстрационные, данные обрабатываются в браузере.
